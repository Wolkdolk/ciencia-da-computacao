# Desenvolvimento Front-End para Web

Repositório com anotações e exercícios práticos das aulas de Front-End.

## Conteúdos Abordados

### [Aula 02](./aula2)
- Introdução ao HTML (estrutura básica)
- Listas ordenadas e não ordenadas (`<ol>`, `<ul>`, `<li>`)
- Tabelas (`<table>`, `<tr>`, `<td>`)

### [Aula 03](./aula3)
- Tabelas (mesclagem e semântica: `<thead>`, `<tbody>`)
- Links (`<a>`)
- Imagens (`<img>`)

### [Aula 04](./aula4)
- HTML Semântico (`<header>`, `<main>`, `<footer>`, `<section>`, `<div>`)

### [Aula 05](./aula-5)
- Formulários (`<form>`, `<input>`, `<label>`, `<button>`)
- Recursos de Multimídia (`<video>`, `<audio>`)
