# Algoritmo e Pensamento Computacional

Repositório com anotações, exercícios e projetos desenvolvidos nas aulas de lógica de programação e Linguagem C.

## Conteúdos Abordados

### [Aula 02](./aula02)
- Pilares do Pensamento Computacional
- Introdução aos Algoritmos
- Introdução à Linguagem C
  - Criação de variáveis (`int`, `float`)
  - Comandos de saída (`printf`)
  - Cálculos básicos (soma, subtração, divisão e multiplicação)

### [Aula 03](./aula03)
- Operadores aritméticos (`+`, `-`, `*`, `/`, `%`)
- Operadores lógicos (`&&`, `||`, `!`)

### [Aula 04](./aula04)
- Operadores relacionais (`==`, `!=`, `>`, `<`, `>=`, `<=`)
- Operadores lógicos
- Estruturas de decisão (`if`, `if-else`, `switch-case`)

### [Aula 05](./aula05)
- Projeto prático aplicando os conteúdos vistos até a Aula 04

### [Aula 06](./aula06)
- Estruturas de repetição (`while`, `do-while`, `for`)

### [Aula 07](./aula07)
- Exercícios de fixação
- Desenvolvimento de projeto

### [Aula 08](./aula08)
- Estruturas de dados homogêneas
- Arrays (vetores)
- Matrizes

### [Aula 09](./aula09)
- Manipulação de arquivos: leitura e escrita

### [Aula 10](./aula10)
- Funções e modularização
